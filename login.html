Sign in

Authenticate with your GitHub account to access ioBroker Bot tools.

Your token is only stored in your browser's sessionStorage and is never sent to any server other than the GitHub API. Create a new token ↗
How to create a token:
  1. Go to GitHub → Settings → Developer settings → Personal access tokens
  2. Create a fine-grained or classic token
  3. For a fine-grained token, grant at least read-only access to the iobroker-bot-orga/iobroker-bot.github.io repository
  4. For a classic token, the read:org scope is sufficient

Access is granted to members of the iobroker-bot-orga organization and outside collaborators of the iobroker-bot.github.io repository.
